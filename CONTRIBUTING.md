# Contributing to BridgeUp

Thanks for your interest in contributing! BridgeUp is an adaptive Python learning platform with in-browser execution via Pyodide/WASM.

## How to contribute

1. **Fork** this repo and clone your fork
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes and test locally
4. Push and open a **Pull Request**

## Good first issues

Look for issues labeled [`good first issue`](https://github.com/gitswagata1/bridgeup/labels/good%20first%20issue) — these are beginner-friendly tasks.

## Areas where help is needed

- **UI/UX improvements** — better mobile responsiveness, accessibility
- **New Python exercises** — contribute practice problems or course content
- **Bug fixes** — check the Issues tab
- **Documentation** — improve setup guides, add inline code docs
- **Testing** — expand test coverage in `tests/`

## Setup

```bash
git clone https://github.com/<your-username>/bridgeup.git
cd bridgeup
npm install
npm start
```

See [SETUP-CLOUD.md](SETUP-CLOUD.md) for Supabase backend setup.

## Code style

- Use consistent indentation (2 spaces for JS/TS)
- Write descriptive commit messages
- Keep PRs focused — one feature or fix per PR
